# EDGEWALK Research Plan

## Scientific and algorithmic boundaries

**H0:** alleged QEC/ETQ/cosmology spectral similarities are explained by graph size, degree, protocol scheduling or graph selection, not shared physics. **H1:** controlled and preregistered structural associations persist beyond meaningful null ensembles. Associations alone do not establish a physical mechanism.

- **v0.1 delivered:** exact binary Golay/CSS rank and distance, X/Z Tanner topology, 303 integer event scheduler, hash-bound baseline.
- **v0.2 delivered:** read-only receipt-pinned ETQ-303 v3 input adapter; real adjacency-tested ETQ and Golay auxiliary walks; exact Laplacian/adjacency moments; non-backtracking combinatorial statistics; optional floating eigenspectrum/IPR; one deterministic degree-preserving topological control per system; separately domain-bound comparison receipt.
- **v0.3 implemented (optional numerical):** sparse non-backtracking modes, Bethe Hessian, grouped projectors, ETQ Cartesian shift, channel-isolated BP fixed-point Jacobians, and paired graph-potential perturbations. Archived ETQ end-to-end remains a separate integration gate.
- **v0.4 implemented (methodology):** three GF(2)-valid Golay check bases; SHA-256-sampled matched per-graph degree-preserving null ensembles; ETQ base-101 rewires that retain the C3 lift; exact four-cycle/fourth spectral moment and matched one/two-edge perturbation receipts; seeded bootstrap intervals; exploratory Holm adjustment; exact replay with tamper detection. The finite-step MCMC ensemble is not proved uniform or independent, so inferential calibration remains an explicit future gate. Genuine SONIFICATION integration is still outstanding.
- **v0.5 implemented (reproducible evidence):** full read-only ETQ-303 v3 bundle and observation-receipt integrity gate, exclusive-create evidence packages, exact experiment replay, deterministic provenance and checksum receipts, sampling diagnostics and conservative supported/inconclusive/not-tested findings. Real ETQ integration execution and statistically calibrated null modelling remain explicit external gates.
- **v0.6 implemented (bounded demonstration):** a registered, read-only NASA planetary Kepler third-law adapter with explicit Earth-anchored equations, external data transcription SHA pin, fixed seven-row holdout statistic, exact enumeration of all 5,040 label permutations, replayed physical-report receipts, and separate calibration flags. Its conditional label null is exactly enumerated; physical observational exchangeability is NOT established, so physical inferential calibration remains unqualified. No Friedmann, dark-sector, QEC-as-spacetime, or (3,2)-signature physical adapter has been admitted. Such adapters remain conditional on genuine independently supported null models and observations.

## What is and is not validated

The *source* ETQ-303 contract is exact finite graph/event mathematics. The *receiver* reports edge walks selected by our explicit schedule rather than original ETQ support steps. Degree-preserving rewires preserve integer degree counts but do not preserve the CSS commutation law, graph product identity, locality or physical provenance. Their moments are useful regression checks but not discriminative under fixed degree sequence.

The v0.2 test suite uses **synthetic** ETQ-shaped fixtures with mocked cryptographic commitments strictly to exercise failures and parser branches. A successful full-bundle integration run requires an actual upstream build directory. Do not report one if it has not been run.
