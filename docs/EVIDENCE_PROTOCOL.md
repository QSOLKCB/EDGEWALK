# EDGEWALK v0.5 — Evidence & Audit Protocol

## Objective

Archive independently reproducible **software evidence**, not a physical validation claim. The result is an immutable-by-convention package with independently checkable SHA-256 commitments, exact deterministic experiment replay and an epistemic findings report.

## Authentic ETQ gate

Source: separately built SONIFICATION ETQ-303 v3.0.0 bundle, not the example canonical contract or a reconstructed graph. First validate original published ETQ semantic hashes, the actual 303-step events and 5364-edge graph, its manifest core and receipt identity. Then verify *all* manifested file bytes and lengths and the observation receipt's receiver commitments. Run locally with python -m edgewalk --validate-etq SOURCE_DIR. Only a successful run may set etqGate=passed. The software cannot establish that those files were generated by nature; this is source and implementation provenance.

## Package / replay

Use --evidence-out NEW_DIR with optional --etq-bundle SOURCE_DIR and declared --control-samples, --control-swaps, --control-seed, --bootstrap-draws, and --control-variants parameters. The destination must not already exist. No overwrite, deletion or source-file modification occurs.

Run --verify-evidence DIR (and the original --etq-bundle where applicable). The verifier checks the manifest file list, each SHA and byte count, checksum listing, complete v0.4 exact evidence replay and original receipt, recomputed calibration diagnostics, deterministic report content and, if supplied, the authentic ETQ source receipts again. Exact submission type changes (e.g. integer to float) must fail replay even when Python structural equality would permit them.

## Calibration status and interpretation

The v0.4 null ensemble is built by finite, deterministic two-switch chains. This release has **not established convergence, stationary sampling, independence or exchangeability**. The v0.5 report adds descriptive first/second-half means, lag-one serial correlation and constant-series flags, all excluded from exact v0.4 receipt identity. There are no calibrated p-values or physical confidence intervals. Any v0.4 Holm-adjusted tail ranks remain exploratory. A genuine calibration claim needs an independently justified sampling model and preregistered experiment, with different exact tests for physical data.

## Findings taxonomy

- Exact software claims: replayable when package verification passes; if ETQ supplied, release-artifact hash integrity supported.
- Cross-domain structural hypothesis: inconclusive pending stronger model and independently validated controls.
- Cosmological/dark-sector/(3,2) theories: not tested here; no evidence accepted for or against.

All negative/null results remain included. No GitHub Actions or external network is needed in normal runtime.


## P1 trust-anchor hardening

The pinning of the ETQ event document and lifted edges in the canonical
contract is **not sufficient** to authenticate arbitrary receiver bytes.
The full v3.0.0 release gate accepts only a complete bundle whose
\`manifest.json\` byte SHA-256 equals the externally supplied
\`trusted_etq_manifest_sha256\`. Because this manifest commits to all eight
payload files (including the observation receipt), that comparison binds the
receiver hashes to the independently acquired manifest commitment.

The pin is a **trust input**, not a digest extracted from \`manifest.json\`
itself and not a value recovered from the same untrusted directory. Until
the publisher archives or publishes that independent full-release digest,
the command without a pin must refuse the \`passed\` verdict. An adversarial
caller who supplies both a forged bundle and its SHA-256 has not established
authenticity; the external origin of the trust input must be checked separately.

## P2 exploratory evidence reconstruction

\`experiment.json\` stores the separate \`analysisParameters.bootstrapDraws\`
integer (32–4096) alongside the original unchanged v0.4 exact evidence. On
verification, regenerate the exact controls, then run the same
\`controls._summarize(exactEvidence, bootstrapDraws)\` and compare canonical
summary bytes. Neither the bootstrap parameter nor the exploratory array
is part of v0.4's domain-separated exact experiment receipt.

Changing an exploratory observation, tail fraction, Holm adjustment,
or percentile interval and fixing all outer file hashes is a verification
failure. No new calibrated significance claim is introduced.
