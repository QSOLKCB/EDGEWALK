# EDGEWALK v0.4.0 — Controlled Spectral Experiment Invariants

1. **Inherited contracts.** v0.1 Golay CSS parameters, v0.2 ETQ source identity and v0.3 numerical qualifiers are untouched. No writes to QEC/SONIFICATION, no implicit network, no GitHub Actions.
2. **Golay representation.** The reference, shear-a and shear-b bases consist of invertible elementary row operations on the same 11-row binary self-orthogonal subspace. Each check basis must pass GF(2) rank 11 and HH^T=0. Basis changes may change Tanner geometry without changing the encoded code.
3. **Graph-only Golay nulls.** Preserve vertex degree **per X/Z channel** and bipartite variable/check incidence using same-channel two-switches. Rewired graphs are not necessarily CSS codes and must never be presented as logical stabilizers.
4. **ETQ product controls.** Require a validated local ETQ bundle. Independently verify G101 square C3 adjacency, extract G101, two-switch only its base edges, retain degree/connectivity, then lift through C3. Nulls are Cartesian graphs but not authentic ETQ root realizations.
5. **Identity-bearing sampler.** All control draws are SHA-256 counter based, rejection-sampled integers, stable lexical vertex and edge order, declared seeds, finite attempts, explicit failure on invalid/duplicate/disconnected controls. No floating eigensolver enters selection.
6. **Predeclared metric family.** FourCycles; unique real edges visited by the 303-event walk; changes in exact Tr(A^4) after removing the first one or two sorted undirected edges. Perturbation rank is matched, but edges have no asserted common physical meaning.
7. **Spectral algebra.** Exact fourth moment identity: Tr(A^4)=2|E|+4 sum_v choose(deg(v),2)+8 C4. Integer combinatorics only; no floating eigenvalues in exact receipts.
8. **Exact receipt.** EDGEWALK/V4/EXPERIMENT SHA256 over compact sorted-key integer/string evidence including full null metric arrays, graph digests, count, seed, algorithms and external ETQ source digests if present. Replay must rebuild controls, not merely rehash a caller's JSON. Auxiliary bootstrap/adjustment output is excluded.
9. **Exploratory statistics.** Seeded percentile bootstrap estimates generated-null mean intervals; observed-to-null median two-sided tail fraction uses +1 numerator/denominator and exploratory step-down Holm adjustment over all predeclared systems/metrics. The finite-step two-switch sampler is not shown stationary, uniform, independent or exchangeable. No calibrated p-values, physics confidence intervals or FWER claims.
10. **Null results remain results.** Never select basis/seed, drop negative comparisons, or tune parameters for compelling spectra after seeing results without labelling that as exploratory. No dark matter, dark energy, quantum spacetime, or 3+2 dimensionality claim is supported.
11. **Verification.** Run the entire Python suite and actual unmodified ETQ-303 integration smoke test before production release. Tests with a synthetic product graph do not verify ETQ archive identity.
